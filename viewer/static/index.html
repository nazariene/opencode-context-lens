How these numbers are measured

Each text part is tokenized independently. Per-part percentages use the sum of visible text estimates; window percentages use the selected model’s full context limit. These estimates exclude message wrappers and are not provider-exact.

Reported input is the latest completed assistant request’s uncached input + cache reads + cache writes. It includes provider-counted overhead, but precedes that reply and subsequent tool results. It is not cumulative session usage and need not equal the visible estimate.
